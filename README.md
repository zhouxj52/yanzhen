# 验真 Yanzhen

把需求变成验收标准，实际执行检查，发现缺陷后提供证据和可复现步骤。

## 已经做了什么

1. **完成前端工作台**：项目概览、验收工作台、运行记录、证据中心、使用指南，适配电脑和手机。
2. **打通验收流程**：输入需求 → 生成契约 → 人工审阅并冻结 → 执行检查 → 查看结果和证据。
3. **接入两个目标**：内置报销系统，以及固定版本的官方 TodoMVC 任务管理示例。
4. **实现真实执行与取证**：使用浏览器和接口检查，保存截图、请求响应及脱敏后的执行轨迹，区分通过、缺陷、受阻和待澄清。
5. **实现缺陷精简复现**：支持四类缺陷，每次删减都在新环境重新执行，最后独立确认两次，并提供复现脚本。
6. **增加证据冲突识别**：识别“保存成功但查询不一致”“新增可见但刷新丢失”。
7. **增加修复标准保护**：审查受限执行计划，拦截放宽断言、更换身份和跳过检查；不会自动应用候选。
8. **补齐基础框架**：任务排队、并发限制、取消、重启恢复、证据 ZIP 下载及完整性校验，提供 CLI 和七个 MCP 工具。

## 怎么运行

已有环境直接启动：

```powershell
& D:/openjiuwen/scripts/start.ps1
```

启动后打开 http://127.0.0.1:8765 。首次安装先运行 D:/openjiuwen/scripts/bootstrap.ps1，需要 Python、uv 和网络。
