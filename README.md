## 怎么运行

**推荐先看演示：**双击项目目录中的“启动演示.cmd”，或运行下面命令：

```powershell
& D:/openjiuwen/scripts/demo.ps1
```

打开后点击“开始真实演示”。演示剧场按五幕展示：定义标准 → 实际执行 → 刷新前后证据 → 精简复现 → 同标准验证修复。支持自动讲解、章节回看、专注模式和修复标准审查；浏览器执行和证据均来自本地真实运行。默认采用离线规则，也可选择已配置的 DeepSeek / Qwen API 解析需求。

已有环境直接启动：

```powershell
& D:/openjiuwen/scripts/start.ps1
```

启动后打开 http://127.0.0.1:8765 。首次安装先运行 D:/openjiuwen/scripts/bootstrap.ps1，需要 Python、uv 和网络。

## 使用 DeepSeek API

在项目本地 .env 中加入以下配置，填入自己的密钥后重启服务，在工作台“分析方式”或演示剧场“需求解析方式”选择 DeepSeek。密钥不会发送到浏览器，不要提交到 GitHub。

```dotenv
YZ_ENABLE_MODEL=1
YZ_DEEPSEEK_BASE_URL=https://api.deepseek.com
YZ_DEEPSEEK_MODEL=deepseek-flash
YZ_DEEPSEEK_API_KEY=填入你自己的密钥
```

DeepSeek 负责把需求整理为受校验的契约，执行和取证继续由本地引擎完成。接口异常会明确报错，不会静默切回离线结果。模型名按 [DeepSeek 官方文档](https://api-docs.deepseek.com/)和账号可用型号配置。当前已验证请求协议和错误处理，尚未使用真实密钥联调。
