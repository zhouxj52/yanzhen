项目还没启动，怎么办？

先选择 GitHub、ZIP 或本地目录导入。纯静态 HTML 项目可以启动预览；其他项目按 README 启动前端和后端，再关联运行地址。

为什么地址可能不能用？

本机、内网和公网地址都需要精确登记到服务器允许列表。公网域名会验证 DNS 并固定连接 IP；复杂第三方登录和跨来源联测仍需要专门配置。

管理员配置说明

在服务器本地配置 YZ_VERIFY_ALLOWED_ORIGINS，登记项目的协议、IP 与端口后重启服务。不要填入凭据。
